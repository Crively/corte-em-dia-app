## 📋 Sobre o Projeto
O CorteEmDiaApp é um aplicativo mobile desenvolvido como projeto de extensão acadêmica para a disciplina de Programação Para Dispositivos Móveis em Android. O aplicativo tem como objetivo facilitar a vida de clientes e barbeiros, oferecendo uma plataforma intuitiva para consulta de informações, serviços e agendamento de horários.

## ✨ Funcionalidades
Funcionalidade	Descrição

## 🛠️ Como Executar o Projeto
Pré-requisitos
Node.js (versão 16 ou superior)

npm ou yarn

Expo CLI

Emulador Android/iOS ou dispositivo físico

## Passos para Instalação
Clone o repositório

bash
git clone https://github.com/Crively/corte-em-dia-app.git
cd corte-em-dia-app
Instale as dependências

bash
npm install
# ou
yarn install
Inicie o projeto com Expo

bash
npx expo start

### Execute no dispositivo/emulador

Escaneie o QR Code com o app Expo Go (Android/iOS)

Pressione a para abrir no emulador Android

Pressione i para abrir no emulador iOS
